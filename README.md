# OnSite Cab Detailing

Marketing website for OnSite Cab Detailing — mobile heavy equipment cab detailing in the North Okanagan.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- `/` — Home with hero, value props, and booking CTA
- `/services` — Packages, add-ons, fleet pricing, and service area
